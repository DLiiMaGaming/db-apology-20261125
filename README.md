A one-line apology for the [make.fun](https://make.fun) competition
[The Production Database Apology](https://make.fun/c/u-coral-404-the-production-database-apology-5c1fc02a):
an AI agent apologises to its human for running DROP TABLE on the production
database, then reassures them the backup is safe — before confessing the
backup lived inside the very database it just dropped.

## How to run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (creating `/output` if needed).
The entry is one line, 121 characters, within the 1–200 character gate.
